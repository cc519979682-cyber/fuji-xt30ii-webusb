# X-T30 II WebUSB 胶片配方仪表盘

**在浏览器中管理 X-T30 II 的 C1–C7 胶片配方。** 通过 USB 读取和备份现有设置，调整已映射的画质参数，用内置参考图或自己的照片查看近似实时预览；确认差异后可逐项写入并回读。无需安装 X RAW STUDIO、上传照片或准备 RAW 样片。本项目是非官方工具，与 FUJIFILM 无关联。

> 已在一台 X-T30 II、固件 2.04 上验证 C 档读取、备份、C1 改名和部分画质参数写入及重连后读回。其他机身、固件和参数组合尚未逐项验证。写入前请保留相机现有设置备份。

## 能做什么

- 读取 C1–C7 的名称和已映射画质参数，下载包含原始 PTP 字节的 JSON 备份。
- 编辑胶片模拟、白平衡、颗粒、色彩效果、色彩、锐度、降噪、清晰度等相机支持的设置。
- 用内置参考图或自己的照片，在浏览器里即时比较大致色调。预览是近似模拟，最终效果以相机 JPEG 为准。
- 写入前重新核对相机状态，逐项写入并回读；发现意外变化即停止。
- 查看[机身上使用 C1–C7 的方法](./camera-guide.html)。

本工具不控制快门、光圈、对焦，也不提供实时取景或备份文件一键恢复。

## 启动

需要带 WebUSB 的 Chrome 或 Edge、Python 3、USB 数据线，以及设为「USB RAW转换/备份恢复」连接模式的 X-T30 II。把相机开机，并退出可能占用相机的 X RAW STUDIO、照片或图像捕捉。

在项目目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

用 Chrome 或 Edge 打开 <http://127.0.0.1:8765/>。macOS 也可在终端运行 `zsh start.command`，由脚本启动服务并打开浏览器。程序无需构建和第三方运行依赖。WebUSB 的设备选择框须由用户在网页上点击「连接 X-T30 II」后打开。

## 使用

1. 连接相机，点击「读取 C1–C7」。读取时会暂时切换 USB 管理用的 C 档选择器，结束时恢复。
2. 点击「下载原始设置备份」，确认文件已保存。**备份内含机身序列号和完整 C 档设置，请勿上传到公开仓库或公开 Issue。**
3. 选择要覆盖的 C 档并调整参数。改动会立即显示在「调整后」参考图，不会立即写入相机。可选择自己的照片；图片仅在当前浏览器页面处理。
4. 核对差异、勾选确认，再点击写入。写入完成后，在相机菜单检查该档能否选用。

「柔和人像」按钮仅为 C1 填入 ASTIA 等示例参数，不会自动写入，也不会修改名称。它保留该档现有的动态范围优先、动态范围、高光和阴影数值。

### 改名的特别步骤

开发期间曾观察到：仅向 C 档名称属性写入时，相机还把该档的多项画质设置改成当前拍摄设置。因此名称和配方必须分两次保存：**先单独改名 → 重新读取 C1–C7 → 再下载备份 → 最后调整配方并写入。** 页面会核对名称写入后的全部属性，出现意外变化会停下。空名称不表示该档没有设置，覆盖前请在相机菜单确认。

## 已知限制与故障处理

- 仅放行 X-T30 II。固件 2.04 上，通过 USB 把「动态范围优先」从自动设为关闭时，相机返回 PTP `0x201C`；页面在该固件上禁用此项写入。需要手动调整动态范围、高光和阴影时，先在相机菜单把「D 范围优先」设为关闭，再重新读取。
- 写入过程中断线可能导致部分参数已改变。页面会锁定旧快照；重新连接并读取相机，保留原始 JSON 备份以便人工核对。当前没有一键恢复。
- USB 回读不能证明 C 档已在机身菜单中可选。若目标档显示「新建」，不要直接执行新建，以免当前拍摄设置覆盖它。
- 预览不是富士 JPEG 引擎；自动白平衡、动态范围优先、场景光线和相机处理可能使真实成片明显不同。
- 若浏览器看不到相机，确认使用数据线、相机连接模式正确，并关闭占用 USB 的其他程序。
